# Social card scrapers — IMPORTANT: use empty `Disallow:` per the 1994 spec,
# NOT `Allow: /`. Facebook's parser doesn't reliably understand the Allow
# extension and may interpret a section with ONLY `Allow: /` as "block all
# except the exact path /", which makes every product/category URL look
# disallowed and causes the Sharing Debugger to report "403 / robots.txt
# block" even though nginx is wide open. The empty `Disallow:` is the
# canonical "nothing is forbidden" instruction every parser understands.
# Reference: https://developers.facebook.com/docs/sharing/webmasters/crawler/
